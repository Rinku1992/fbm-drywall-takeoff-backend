## Introduction
#### XTIMATOR is an AI-Powered automated construction estimation system designed to generate accurate drywall material quantities directly from architectural floor plans. It leverages structured wall geometry, room polygons, ceiling configurations, openings and architectural scale information to computes drywall surface areas and material requirements for both walls and ceilings while accounting for project-specific waste factors and installation constraints.
